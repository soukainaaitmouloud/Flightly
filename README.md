\# Flightly — Flight Booking Website



## About the Project



Flightly is a flight booking website developed as a web development project. It allows users to explore destinations, compare flight options, enter passenger information, select seats, and complete a demo booking.



## Features



- Flight search and flight results

- Flight sorting options

- Passenger information form with validation

- Interactive seat selection

- Booking summary and automatic price calculation

- Demo payment form (no real payments are processed)

- User sign-up, login, and logout interface

- Popular destination cards

- Responsive layout for desktop and mobile screens



## Technologies Used



- HTML5

- CSS3

- JavaScript

- Supabase integration configuration (for account authentication, if configured and connected)



## Project Purpose



This project demonstrates practical web development skills, user interface design, form validation, booking workflow logic, and responsive design.



## Important Note



Flightly is a demonstration project. Flight results and prices are sample data, and the payment form does not process real payments or issue real flight tickets.



## How to Run



1\. Download or copy the project folder.

2\. Keep `index.html`, `style.css`, `script.js`, `auth-config.js`, and the `images` folder together.

3\. Open `index.html` in a web browser.

4\. For features that require a backend or authentication service, configure the necessary service settings first.



## Project Status



The main demo booking journey has been tested, including passenger details, seat selection, demo payment, and booking confirmation. Further testing and documentation can improve the project.
