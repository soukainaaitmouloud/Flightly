# ✈️ Flightly — Flight Booking Website Demo

A responsive flight booking website built with HTML, CSS, and JavaScript. Flightly demonstrates a complete booking journey, from searching for flights to selecting seats and confirming a demo booking.

🔗 **Live Demo:** [Open Flightly](https://soukainaaitmouloud.github.io/Flightly/)

## 📌 Project Overview

Flightly is a front-end web development project designed to simulate the user experience of an online flight booking platform. Users can explore sample flights, enter passenger details, select seats, review booking information, and complete a demo checkout.

## ✨ Features

- **Flight Search:** Search available sample routes and view flight results.
- **Flight Sorting:** Organize flight results using available sorting options.
- **Passenger Details:** Enter passenger information with form validation.
- **Interactive Seat Selection:** Choose seats and view the associated prices.
- **Booking Summary:** Review booking details and automatically calculated prices.
- **Demo Checkout:** Complete a simulated payment and receive a booking confirmation.
- **User Authentication:** Sign up, log in, and log out using Supabase authentication when configured.
- **Destination Cards:** Explore featured destinations.
- **Responsive Design:** Use the website on desktop and mobile screens.

## 🚀 Getting Started

To run the project locally:

1. Clone or download this repository.
2. Keep `index.html`, `style.css`, `script.js`, `auth-config.js`, and the `images` folder together.
3. Open `index.html` in your browser, or use a local development server.
4. Configure the Supabase project settings if you want to test authentication.

## 🧪 Demo Limitations

- Flight routes, availability, and prices are sample data.
- No real flights are searched or booked.
- The checkout is for demonstration purposes only.
- No real payment is processed, and no real flight ticket is issued.
- Authentication requires a correctly configured Supabase project.
